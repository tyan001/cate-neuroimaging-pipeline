NAMING SUMMARY
  subject dir     110001                             bare 6-digit ID
  session dir     20200115                           bare YYYYMMDD
  image file      <subjid>-<YYYYMMDD>_<SUFFIX>.nii   hyphen, then underscore
  recon dir       <subjid>-<YYYYMMDD>_<T1w|CorMPRAGE>   = anat filename stem
  SUVR PET dir    <subjid>-<YYYYMMDD>_PET[_<recon>]     = pet filename stem
  SUVR pair dir   <subjid>_pet_<petdate>_mri_<mridate>  underscores throughout
  result file     <pairdir>_<measure>.csv

  All images are uncompressed .nii — there are no .nii.gz files in the tree.
